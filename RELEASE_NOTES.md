# Residents Directory releases

## V4.0 — 27 October 2026

- Resident popup actions: Text, phone icon, video camera icon, Email and Map.
- Video action opens the resident's WhatsApp chat using the existing phone number in international format. Tap WhatsApp's video camera to start the call. No call starts automatically.
- Shorter screens use a smaller photo, even compact spacing, scrollable resident details and contact actions that stay visible. Buttons retain 44px touch targets.
- Phone and video icons have accessible labels; video is hidden when no suitable number is recorded.
- Updated the app shell cache for the release. Existing installations retain the Reload update prompt.

## V3.0 milestone

The completed directory at commit `6614c14` is preserved as the annotated `v3.0` milestone: resident directory, photo profiles, search, contact actions, interactive village map and compact header controls.

Before V4.0 changes, a full copy of the repository (including Git history), the V4 preview and the V3.0 master workbook was saved locally in `Backups/pre-v4.0-20261027-135516` in the Residents Directory chat workspace.

V4.0 is a web-app release. The master workbook remains V3.0 because these changes do not alter its data or macros.
